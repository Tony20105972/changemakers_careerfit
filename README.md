# CareerFit

CareerFit is a Career Intelligence Platform.

Mission:

> Translate human experience into the language of jobs.

---

# Vision

CareerFit helps users understand:

- What skills they already possess
- How their experiences map to job requirements
- What gaps exist between current and target roles
- What actions will maximize career growth

---

# V1 Scope

Supported Job Families:

- HR
- Marketing
- Data
- Product
- Operations

Core Features:

- Career Intake
- Evidence Extraction
- Skill Mapping
- Job Requirement Matching
- Fit Scoring
- Gap Analysis
- Recommendation Engine
- PDF Report Generation
